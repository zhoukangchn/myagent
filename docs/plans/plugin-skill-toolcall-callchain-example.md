# 示例：Plugin / Skill / Tool call 一次完整调用链（教学用）

> 目的：用一个最小例子把三者职责彻底钉死，避免新手把 plugin 当成“只在启动时干活的配置文件”。

## 问题
用户：帮我查一下上海明天会不会下雨？

## 调用链（概念版）
1. **OpenClaw 选择/注入相关 Skill**
   - 把“查天气的流程知识”塞进提示词：需要哪些参数（城市/日期）、优先用哪个 tool、失败如何降级、输出格式等。
2. **模型根据 Skill 的提示，发出 tool call**
   - 例如：`get_weather(city="上海", date="明天")`
3. **OpenClaw 路由 tool call → 对应 Plugin 的工具实现**
   - 例如：`WeatherTool`（在 plugin 内）
4. **Plugin 在运行时执行真正的工作**
   - 调天气 API / 做重试限流 / 解析响应 → 返回结构化结果
5. **模型把结果组织成用户能懂的回答**
   - 是否下雨、温度区间、体感、带伞建议等

## 3 句口诀（强记忆版）
- **Plugin 给“手和工具箱”**：能访问外部世界、能执行。
- **Skill 给“说明书和操作步骤”**：教你怎么用工具箱。
- **Tool call 是“按下按钮”**：模型决定调用哪个工具、传什么参数。
