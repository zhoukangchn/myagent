# Runtime Notes

## Windows

```powershell
npm i -D playwright
npx playwright install chromium
node scripts/scrape_xinsheng.js --url "<list-url>" --pages 2 --out outputs/posts.json
```

## Linux/CI

```bash
npm i -D playwright
npx playwright install chromium
node scripts/scrape_xinsheng.js --url "<list-url>" --pages 2 --out outputs/posts.json
```

If site rendering is delayed, increase `--wait-ms`.

## Login / Cookie Options

- Inline cookie header:
  - `--cookie "k1=v1; k2=v2"`
- Cookie from file:
  - `--cookie-file ./cookies.txt`
- Reuse Playwright storage state (recommended for login-required pages):
  - `--storage-state ./storageState.json`

`storageState.json` can be generated by a one-time manual login flow in Playwright and then reused in headless runs.

Generate it with:

```bash
node scripts/save_storage_state.js --url "https://xinsheng.huawei.com/next/index/#/home" --out ./storageState.json --headful --timeout-ms 180000
```

## Expected Input

- List URL format: `https://xinsheng.huawei.com/next/index/#/list?...`
- Public content only.

## Output Fields

- `title`
- `detailUrl`
- `author` (heuristic)
- `publishTime`
- `latestReply`
- `views`
- `replies`
- `content` (only when `--detail`)

## Trend Analysis

Generate a markdown trend brief from scraped JSON:

```bash
node scripts/analyze_trends.js --input outputs/posts.json --out outputs/trend-report.md
```

The script outputs:
- theme distribution
- high-frequency keyword hints
- community trend conclusions
- short operations recommendations
